# Анализ обозначений NC/AC/PU/PE/UV/WB - Краткая сводка

## Главный вывод

**NC/AC/PU/PE/UV/WB — это ХИМИЧЕСКИЕ СЕМЕЙСТВА (типы связующего вещества), а НЕ роли слоёв или типы покрытий.**

Это фундаментальное различие:

```
НЕПРАВИЛЬНО:
  PU = полиуретановое покрытие (тип покрытия)
  primer = роль слоя

ПРАВИЛЬНО:
  PU = полиуретановый (химическое семейство)
  primer/isolator/topcoat = роль в системе нанесения
```

## Ключевые находки

### 1. Один продукт может быть разным в разных системах

```
PU (химическое семейство)
  ↓
  - ПУ-праймер (роль: primer)
  - ПУ-изоляционный силер (роль: isolator)
  - ПУ-краска (роль: topcoat)
  - ПУ-лак (роль: topcoat)
```

### 2. Одна роль может быть из разных химических семейств

```
primer (роль)
  ↓
  - ПУ-праймер (PU)
  - Трэфф Тэксурф (AC)
  - Грунт Аквапраймер (WB)
```

### 3. Система может смешивать химические семейства

Пример: **Кислотная пигментированная система с изолянтом**
- isolator: ПУ-изоляционный силер (PU семейство)
- primer: Трэфф Тэксурф (AC семейство)
- topcoat: Профф 355 (AC семейство)

### 4. Совместимость НЕ определяется только химическим семейством

**ВАЖНО**: `PU на PU` ≠ автоматически совместимо!

Примеры проблем:
- PU с цинк стеаратом на PU без него → проблемы адгезии
- PU на NC → активный разбавитель может вспучить NC
- PU на WB → активный разбавитель может вспучить WB

Нужна матрица совместимости из документации, а не просто сравнение кодов.

## Матрица совместимости (кратко)

| Top → Base ↓ | NC | AC | PU | PE | UV | WB |
|---------------|----|----|----|----|----|----|
| **NC** | — | ✗ | ✓ | ✓ | ✓ | ✗ |
| **AC** | ✓ | — | ✓ | ✓ | ✓ | ✗ |
| **PU** | ✓ | ✓ | — | ✗ | ✗ | ✗ |
| **WB** | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| **UV** | ✗ | ✓ | ✓ | ✓ | — | ✗ |

✓ = Совместимо | ✗ = Несовместимо (с условиями) | — = То же семейство

- Поле `coating_type` (дублирует `chemical_system`)
