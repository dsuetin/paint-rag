# Аудит источников данных совместимости и систем покрытия

Формат: строго по фактам из источников. Каждая подтверждённая связь имеет
цитату + источник (файл, лист/страница). Всё неуточнённое — `UNKNOWN`.
Правило «оба по химии одного класса → совместимы» НЕ используется.
Использование продукта («для МДФ») не трактуется как совместимость слоёв.

систем `layers` содержит 10-20 объектов по 1-2 слова. **Нужен ре-парсинг.**

«оба PU → совместимы» запрещён** — эти правила НЕ являются таким выводом
(это явные пары химий), но источник у большинства отсутствует →
следует помечать `legacy=True`.

### `data/knowledge/products.json` — 40 продуктов, `role` НЕ заполнен нигде
Модель `Product` поддерживает `role: ProductRole | None`,
но в JSON ни один продукт `role` не получает.
`RoleSubstrateSource`/`ProductRole` — модель готова к использованию,
но **импортёр не заполняет**.

### `data/knowledge/calculations.json` — 13 правил
Пропорции отвердителя/разбавителя по продуктам — рецептура смешивания,
